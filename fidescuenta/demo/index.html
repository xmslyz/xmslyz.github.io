Sample files

All data in these files is fictitious (made-up names, tax IDs and amounts). They let you try every feature of FidesCuenta that reads a file. No account or login is needed.

Download all: FidesCuenta-sample-files.zip (6 files)

Quickest path: a ready-made book

  1. Download Club_Deportivo_Demo.fcbackup.
  2. In FidesCuenta, open the book menu (toolbar, books icon) → Restore from backup… and choose the file. On first launch, choose No, create a new book, create any book, then restore.
  3. The book “Club Deportivo Demo” (country Ecuador, RUC 0990000000099) appears with 3 wallets, categories, income, expenses, a transfer and a member's own expense (Reimbursements). Choose it in the book menu.

Files and where to use them

FileFeatureWhere in the app
comprobantes_recibidos_demo.txt Import of the SRI “comprobantes recibidos” list (3 invoices) Invoices → Import → Import SRI file…. In the demo book one invoice links automatically by its number, the other two show the proposed expense.
factura_001-002-000004512_demo.xml Invoice XML with line items Invoices → Import → Import XML files…. The invoice then shows its items (football, hand pump).
categorias_club_demo.csv Import of categories from CSV Categories → Import from CSV…
Recibo_demo.pdf Document attached to an expense Register → open an expense → Edit → Document photos → From files.
FidesCuenta2_demo.db Migration from the previous version (FidesCuenta 2, a desktop program) Book menu → Import from FidesCuenta 2…. Creates a new book “Parroquia Demo”.
Club_Deportivo_Demo.fcbackup Backup and restore Book menu → Restore from backup… (and Back up this book… to create one).

Features that need no file

  • Reports: Reports → choose period → Create report → PDF, CSV or Print.
  • Roles: book menu → Members and roles…; View as shows the book as another role, read-only.
  • iCloud sync and sharing (optional): book menu → iCloud sync… → Invite to this book… (needs a second Apple ID).
